# NEON RACE — GitHub Pages package

Публичная статическая сборка НЕОН-РЕЙС для размещения на GitHub Pages и последующего тестирования в Pikabu Games Studio.

## Состав

- `index.html` — игра целиком; графика и звук создаются внутри HTML/Canvas/Web Audio.
- `.nojekyll` — отключает обработку Jekyll; GitHub Pages публикует файлы напрямую.
- `PIKABU_SETUP_RU.md` — настройка GitHub Pages и проверка в Пикабу.

## Быстрая публикация GitHub Pages

1. Создайте **публичный** репозиторий `neon-race-pikabu`.
2. Загрузите в корень репозитория содержимое этой папки (не сам ZIP): `index.html`, `.nojekyll`, `README.md`, `PIKABU_SETUP_RU.md`.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Дождитесь успешного GitHub Pages deployment в Actions или ссылки **Visit site** в Settings → Pages.
7. Адрес проекта будет иметь вид `https://<GITHUB-USERNAME>.github.io/neon-race-pikabu/`.

## Важные ограничения

- Публичный репозиторий и опубликованный сайт доступны всем. Не помещайте в него пароли, секретные ключи, токены или приватные данные.
- GitHub Pages — статический хостинг: он не запускает серверный код и не может безопасно хранить секреты для проверки платежей.
- SDK Pikabu загружается с `https://games.pikabu.ru/sdk/sdk.js`; вне тестового/боевого окружения Пикабу игра должна оставаться работоспособной в локальном режиме.
- В документации Пикабу указано размещение игры на собственном сервере. GitHub Pages — инфраструктура GitHub, а не ваш собственный сервер. До отправки игры на модерацию уточните у поддержки Пикабу, принимают ли они `github.io` в качестве URL хостинга. Если нет — используйте хостинг, который одобрит Пикабу, либо GamePush.

## Баланс survivor-прогрессии без стрельбы (v5.3)

Версия 5.3 сохраняет исходную концепцию НЕОН-РЕЙС: игрок **только уворачивается** от астероидов, ворот и событий. В игре нет оружия, автоматической стрельбы, снарядов или уничтожения препятствий. От survivor-аркад взят только принцип роста силы персонажа — внутри забега и между забегами.

- **Повышение уровня в полёте:** собранные звёзды дают опыт забега. При повышении уровня игра останавливается и предлагает выбрать одно из трёх временных усилений.
- **Временные усиления:** форсаж, щит, аварийный ремонт, гравитационный захват, поле стазиса (замедляет препятствия), фазовый след (увеличивает неуязвимость после столкновения) и сканер-эхо (чаще создаёт звёзды).
- **Постоянная мастерская:** двигатель, магнит, корпус, сканер, реактор и экранирование. Новый постоянный щит даёт заряд защиты в начале каждого полёта; корпус добавляет жизни, двигатель усиливает манёвренность, магнит и сканер помогают собирать ресурсы.
- **Восемь кораблей:** «Фантом» и «Валькирия» специализируются на манёвренности; «Страж» и «Бастион» — на живучести; «Магнит» и «Шторм» помогают собирать звёзды; «Призрак» один раз спасает от столкновения.
- **Кривая сложности:** первые 20 секунд остаются опасными; после 20-й секунды плотность и скорость препятствий растут заметнее. После 75-й секунды и особенно после 110-й секунды давление выше, чем в базовой кривой 5.1. Постоянная прокачка и выбор корабля должны помогать выдерживать эту эскалацию, а не выключать сложность.
- **Экономика:** звезда приносит 2 кристалла (4 во время «Кристального раша»). Бонус за завершение зависит только от времени и счёта; гарантированного минимума больше нет. Получение XP замедлено, цены кораблей и основных улучшений возвращены к прежним значениям. Добровольная rewarded-реклама даёт 25 кристаллов.
- **Постоянное экранирование:** два уровня стоят 160 и 300 кристаллов соответственно; это сильная защитная система, рассчитанная на долгосрочную цель.
- **Совместимость сохранений:** ключ neonRaceProgress_v3 и текущий прогресс сохранены. Новое улучшение щита автоматически добавляется старым профилям с нулевым уровнем; сброс профиля не нужен.

## Реклама в Pikabu Games

- **Fullscreen** автоматически запрашивается после завершения каждого полёта, только если Pikabu SDK сообщает, что формат поддерживается и показ доступен. SDK самостоятельно применяет минимальный интервал 120 секунд.
- Если реклама недоступна или возникает ошибка, экран результатов открывается без блокировки игрока.
- **Rewarded** остаётся добровольной: игрок нажимает кнопку и получает 50 кристаллов только при `reward: true`.

Игра использует русскую локализацию по умолчанию и переключатель RU/EN.
