# NEON RACE — GitHub Pages package

Публичная статическая сборка НЕОН-РЕЙС для размещения на GitHub Pages и последующего тестирования в Pikabu Games Studio.

## Состав

- `index.html` — игра целиком; графика и звук создаются внутри HTML/Canvas/Web Audio.
- `.nojekyll` — отключает обработку Jekyll; GitHub Pages публикует файлы напрямую.
- `PIKABU_SETUP_RU.md` — настройка GitHub Pages и проверка в Пикабу.

## Быстрая публикация GitHub Pages

1. Создайте **публичный** репозиторий `neon-race-pikabu`.
2. Загрузите в корень репозитория содержимое этой папки (не сам ZIP): `index.html`, `.nojekyll`, `README.md`, `PIKABU_SETUP_RU.md`.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Дождитесь успешного GitHub Pages deployment в Actions или ссылки **Visit site** в Settings → Pages.
7. Адрес проекта будет иметь вид `https://<GITHUB-USERNAME>.github.io/neon-race-pikabu/`.

## Важные ограничения

- Публичный репозиторий и опубликованный сайт доступны всем. Не помещайте в него пароли, секретные ключи, токены или приватные данные.
- GitHub Pages — статический хостинг: он не запускает серверный код и не может безопасно хранить секреты для проверки платежей.
- SDK Pikabu загружается с `https://games.pikabu.ru/sdk/sdk.js`; вне тестового/боевого окружения Пикабу игра должна оставаться работоспособной в локальном режиме.
- В документации Пикабу указано размещение игры на собственном сервере. GitHub Pages — инфраструктура GitHub, а не ваш собственный сервер. До отправки игры на модерацию уточните у поддержки Пикабу, принимают ли они `github.io` в качестве URL хостинга. Если нет — используйте хостинг, который одобрит Пикабу, либо GamePush.

## Реклама в Pikabu Games

- **Fullscreen** автоматически запрашивается после завершения каждого полёта, только если Pikabu SDK сообщает, что формат поддерживается и показ доступен. SDK самостоятельно применяет минимальный интервал 120 секунд.
- Если реклама недоступна или возникает ошибка, экран результатов открывается без блокировки игрока.
- **Rewarded** остаётся добровольной: игрок нажимает кнопку и получает 50 кристаллов только при `reward: true`.

Игра использует русскую локализацию по умолчанию и переключатель RU/EN.
