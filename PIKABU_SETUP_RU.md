# Публикация НЕОН-РЕЙС на GitHub Pages и тестирование в Пикабу

## A. Создание репозитория

1. Войдите в GitHub.
2. Нажмите **New repository**.
3. Repository name: `neon-race-pikabu`.
4. Выберите **Public**.
5. README можно оставить выключенным (он уже есть в пакете).
6. Нажмите **Create repository**.

## B. Загрузка игровых файлов

1. Откройте пустой репозиторий.
2. Нажмите **Add file → Upload files**.
3. Перетащите в окно загрузки файлы из папки `NEON_RACE_GITHUB_PAGES`:
   - `index.html`
   - `.nojekyll` (важно: это скрытый файл; если проводник его не показывает, включите показ скрытых файлов)
   - `README.md`
   - `PIKABU_SETUP_RU.md`
4. Внизу страницы нажмите **Commit changes**.
5. Убедитесь, что `index.html` находится именно в корне репозитория, а не внутри дополнительной папки.

## C. Включение GitHub Pages

1. В репозитории откройте **Settings**.
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment** в поле **Source** выберите **Deploy from a branch**.
4. В поле **Branch** выберите `main`.
5. В поле папки выберите `/(root)`.
6. Нажмите **Save**.
7. Откройте вкладку **Actions** и дождитесь успешного задания Pages build/deployment. В Settings → Pages появится **Visit site**.
8. Откройте адрес сайта. Формат: `https://ВАШ-ЛОГИН.github.io/neon-race-pikabu/`.

Публикация может занять несколько минут. Если страница не обновилась, проверьте результат workflow во вкладке Actions и обновите браузер без кеша.

## D. Проверка сайта до Пикабу

1. Откройте URL GitHub Pages в Chrome.
2. Убедитесь, что стартовый экран отображается на русском языке.
3. Переключите язык на English и обратно на Русский.
4. Начните игру; проверьте управление стрелками/WASD и экранные кнопки на телефоне.
5. Проверьте ангар, улучшения, кристаллы, профиль и сохранение после перезагрузки.
6. Вне Pikabu SDK может быть недоступен — это ожидаемо. Локальная игра должна продолжать работать с локальным сохранением.

## E. Подключение в Пикабу

1. В Пикабу Студии откройте карточку игры и раздел тестирования.
2. Создайте тестовое окружение и укажите HTTPS URL GitHub Pages.
3. Откройте выданную Пикабу тестовую ссылку, а не просто URL `github.io`.
4. В тестовом окружении проверьте инициализацию Pikabu SDK, облачное сохранение, авторизацию и rewarded-рекламу.
5. Не отправляйте production на модерацию, пока все пункты не проверены.

## ВАЖНО: подтвердите допустимость GitHub Pages у Пикабу

Официальные технические требования Пикабу говорят о размещении игры на собственном сервере и рекомендуют GamePush, если разработчик не готов самостоятельно размещать игру. GitHub Pages отдаёт статические файлы с инфраструктуры GitHub, то есть это не физически ваш сервер. Поэтому до окончательной публикации получите подтверждение от поддержки Пикабу, что URL `github.io` подходит под их требования. Если они не принимают GitHub Pages, сохраните этот пакет и перенесите те же файлы на хостинг, одобренный Пикабу.

## F. Автоматическая полноэкранная реклама между полётами

- После завершения полёта результат и игровой прогресс рассчитываются и сохраняются.
- Игра проверяет `sdk.ads.fullscreen.isSupported` и вызывает `sdk.ads.fullscreen.canShow()` непосредственно перед показом.
- Если SDK разрешает показ, игра приостанавливает Web Audio и вызывает `sdk.ads.fullscreen.show()` до отображения экрана результатов.
- Если формат не поддерживается, показ недоступен, сработал cooldown или SDK вернул ошибку, игра без задержки показывает результаты и позволяет начать следующий полёт.
- Минимальный интервал между полноэкранными показами — 120 секунд; его обеспечивает Pikabu SDK. Реклама не запускается во время активного полёта.
- Rewarded-реклама за 50 кристаллов остаётся отдельным добровольным форматом.

## G. Диагностика Fullscreen в Pikabu Sandbox

Тестовое окружение Пикабу использует заглушки вместо настоящих рекламных баннеров. Поэтому отсутствие видеоролика на экране само по себе не доказывает ошибку интеграции.

1. Откройте игру по ссылке `games.pikabu.ru/sandbox/...`.
2. Откройте инструменты разработчика браузера (F12) и перейдите на вкладку **Console**.
3. Выполните один игровой полёт до экрана результатов.
4. Найдите сообщения с префиксом `[NEON-RACE][Fullscreen]`.
5. Интерпретация:
   - `availability check {isSupported: false}` — Fullscreen не поддерживается в этом окружении/для игрока.
   - `canShow() returned false` — SDK сейчас не разрешает показ.
   - `calling show()` и `show() result {rendered: true}` — SDK подтвердил отображение рекламного слота; sandbox может показывать заглушку, а не настоящий рекламный ролик.
   - `show() result {rendered: false, reason: ...}` — смотрите код причины (например, `COOLDOWN_ACTIVE`, `UI_BUSY`, `NOT_SUPPORTED`).
   - `SDK does not expose ads.fullscreen` — объект Fullscreen отсутствует; приложите лог в обращение в поддержку Пикабу.
6. После теста скопируйте сюда всю последовательность сообщений `[NEON-RACE][Fullscreen]` либо приложите скриншот Console.

В официальной документации Pikabu Fullscreen показ ограничен интервалом не менее 120 секунд. Метод `canShow()` проверяется непосредственно перед вызовом `show()`.

## Безопасность

- Не добавляйте в репозиторий секретный ключ Пикабу, пароли или токены.
- GitHub Pages не исполняет backend-код. Проверку подписей покупок и другие операции с секретным ключом нельзя безопасно делать в `index.html`.
- В этой сборке реальные покупки не включены; rewarded-реклама использует API SDK Пикабу.

## H. Проверка survivor-прогрессии (v5.0)

1. **Новый или чистый профиль:** начните полёт на «Стриже» без постоянных улучшений. Убедитесь, что старт требует постоянного уклонения и что автопушка самостоятельно наводится на астероиды.
2. **Пушка:** дождитесь появления астероида, проследите за снарядом и убедитесь, что попадания уменьшают прочность, а уничтоженные астероиды исчезают.
3. **Уровень внутри забега:** соберите звёзды. После накопления опыта откроется выбор из трёх карточек, а игровой процесс на время выбора остановится. Выберите бонус и проверьте, что он действует.
4. **Разные сборки:** в нескольких забегах выбирайте разные сочетания скорости стрельбы, урона, мультивыстрела, щитов, форсажа, магнита и ремонта.
5. **Постоянная прокачка:** в мастерской улучшите «Импульсную пушку», двигатель, корпус и магнит. После нового старта проверьте, что постоянные бонусы действуют сразу.
6. **Корабли:** проверьте специализированные бонусы «Валькирии», «Бастиона» и «Шторма»; разблокированные корабли должны оставаться доступными после перезагрузки.
7. **Совместимость сохранений:** старые локальные и облачные профили должны загружаться без сброса. У нового улучшения пушки на старом профиле начальный уровень 0.
8. **Платформенные функции:** повторно проверьте кристаллы, rewarded +50, Fullscreen между полётами и облачную синхронизацию. Эти интеграции не должны зависеть от выбора усилений.

**Критерий баланса:** без улучшений игроку тяжело выжить; внутри забега он собирает рабочую сборку; между забегами постоянные улучшения и корабли заметно облегчают последующие попытки. Это должно ощущаться как рост силы, а не как простое повышение скорости препятствий.
